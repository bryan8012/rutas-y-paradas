## Breve descripción del proyecto
**TransExpress SmartRoute** es un Sistema de Gestión Operativa web diseñado para administrar y controlar la logística diaria del transporte de personal. Está pensado para coordinadores de logística y conductores de buses corporativos, resolviendo el problema de la falta de control en tiempo real sobre las rutas, la asignación de viajes y la verificación de abordaje de los empleados.

## Descripción
Este proyecto permite gestionar la operación logística mediante una aplicación web sencilla, organizada y funcional. Incluye un sistema seguro de inicio de sesión, creación del inventario de la flota de vehículos, configuración de rutas físicas, asignación de turnos y un panel para el seguimiento de abordaje (check-in) en tiempo real, adaptado tanto para pantallas de escritorio como móviles.

## Tecnologías utilizadas
* Next.js (App Router)
* React
* TypeScript
* Tailwind CSS
* Node.js
* Prisma ORM

## Base de datos utilizada
* PostgreSQL

## Funcionalidades principales
* Registro e inicio de sesión seguro de usuarios.
* Creación de registros de la flota vehicular (placas, capacidad).
* Configuración de rutas y puntos de parada.
* Asignación de conductores y vehículos a un viaje específico.
* Registro de check-in (abordaje) de pasajeros con captura de coordenadas GPS.
* Interfaz web responsiva con Modo Nocturno para conductores.
